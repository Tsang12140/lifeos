# LifeOS 字体说明

LifeOS 的界面字体切换使用当前 Windows 用户已安装的字体族名，不把下面三款字体文件复制进 web 静态产物：

- MiSans：小米官方字体，使用时需遵守 [MiSans 字体许可协议](https://hyperos.mi.com/font/en/download/)，并在软件中注明使用 MiSans。
- Source Han Sans / 思源黑体：Adobe 开源字体，适用 SIL Open Font License 1.1；官方来源为 [adobe-fonts/source-han-sans](https://github.com/adobe-fonts/source-han-sans)。
- HarmonyOS Sans：华为官方字体包，来源为 [HarmonyOS 设计资源](https://developer.huawei.com/consumer/cn/design/resource-V1/)。

本机安装的字体由用户自行管理；LifeOS 设置页只保存当前浏览器的字体选择，不会上传字体文件或写入 SQLite。
