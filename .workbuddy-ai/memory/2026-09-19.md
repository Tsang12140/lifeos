### 硬结论：`.timeline-content` 的宽度公式必须含边框
- 全局 `* { box-sizing: border-box }`，所以 `width: calc(3 * 5 * 1.617rem + 2 * 6px + Npx)` 里的 N
  必须 = 左右内边距 28 + **左右边框 2** = **30**。
- 漏这 2px 的后果不是「有点挤」：内容盒 398.078px vs 网格需要 400.08px，浏览器把三条轨道钳到
  **128.688px**，「5 行格子」实际只有 4.975 行。
- **与视口无关**：1920 / 1680 / 1440 量到的数字一模一样 —— 因为 `.timeline-content` 是**定宽**，
  不是按窗口算的。所以「换个窗口就好了」这种猜测在这里是错的。
- 量法：`getComputedStyle(grid).gridTemplateColumns` 直接给出解析后的三条轨道像素，比量 cell 更直观。
