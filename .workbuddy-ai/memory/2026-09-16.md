## 追加修：照片与输入框之间的留白（04:55）

主人反馈「加好照片后离输入框底部有一段留白，很难看」。根因：上一版把 `min-height:130px` 挂在 **`.composer-entry`（整框）** 上，而 textarea 高度由 `MentionBox` **内联写死**（2 行 ≈ 81px）。整框被撑到 130px、textarea 只 81px，**多出的 ~49px 全落在 textarea 下方**，正好夹在最后一行文字和照片带之间。

**修法**：把这根下限从「框」挪到「文字列」——`.composer-entry { min-height: 0 }` + `.composer-entry > .composer-input { min-height: 118px }`。整框高度从此 = 两子元素之和，照片带紧贴文字列下沿，空白无处可放。118px = 原两行 81px + 原整框余量，**空态观感不变（整框仍 145px）**，有图时整框贴合照片。

**实测**：空态 `zone.top - input.bottom = 0px`（那 1px 是透明缝预留）；有图态 `strip.top - input.bottom = 10px`（= 照片带自身 `padding-top:9px` 的刻意呼吸）。修复前两者均 ~~48px~~。探针新增 2 条断言 → **82/82**，`.review/composer-shots.txt` 末行 `RESULT: PASS`。typecheck 绿、`npm test` 44/44。

**新坑**：
1. **`min-height` 挂哪个元素是全部关键**——挂外框撑的是框、多余量堆在子元素旁；挂内容撑的是文字区、外框自然贴合。以后调这区域高度先想清楚要「放大框」还是「放大文字区」。

## 追加：计数/清空按钮贴底（06:20）

### 根因（量出来的，不是猜的）

- `flex-end` 解决盒子对齐（钉到行底，与照片同一条 9px 线）。
- 那 2px 是**视觉**对齐：文字行盒底边含半行 leading，比「清空」药丸的描边底边浅，不补 2px 数字看着比按钮高。

### 新学到

1. **「对齐」有两种，别混**：盒子对齐（`flex-end`）解决不了文字与药丸的**视觉**对齐。判据一律量元素的 `getBoundingClientRect().bottom`，不要量行盒、不要凭肉眼。补 `padding-bottom` 时要知道**它会改变容器尺寸**。

**两个新发现（都写进方案了）**：

1. **`partly-cloudy` 实际渲染成雾**（不是上一轮记的"默认空白背景"）。`WeatherBackground.tsx` 的分支顺序里没有 `partly-cloudy`，落到最后的 `foggy` 分支 → DOM 是 3 条 `.fog-line`，且 `.fog-line` 的基础规则不受 `.weather-bg--foggy` 作用域限制，所以**三条灰条真的画出来了**。即"多云"现在看起来像"雾"。

### 新学到的（可复用）

1. **无缝滚动纹理的通用解法**：条纹用 `repeating-linear-gradient(90deg, …)` 沿**元素本地 x 轴**排布，动画写 `rotate(θ) translate3d(n·period, 0, 0)`。平移发生在旋转后的本地坐标系里、位移是图案周期整数倍 → **像素级无缝，换任何角度都不用重算三角函数**。雪场同理（`rotate(6deg)` + 沿 y 平移一个 tile 高）。
2. **`filter` + `transform` 动画 = 栅格化一次**（模糊在合成层里只算一次，之后只平移）。真正贵的是**动画 `filter` 本身**（旧 `lightning-flash` 动 `drop-shadow` = 每帧重算）。
3. **CDP 验时段相关 UI 的两个手法**：形态用 `localStorage` 驱动（一个注入脚本反复 `Page.navigate`）、时段用 stub `Date`（`FakeDate.prototype = RealDate.prototype` + `FakeDate.now = () => RealDate.now()`，否则 `Intl.formatToParts(new Date())` 会拿到非 Date）。**初始页 `about:blank` 没有 origin，`localStorage.setItem` 会静默失败** → 进循环前必须先导航一次（本轮第一张「黎明」因此拍成了 morning）。
4. **审计动画性能的白名单写法**：遍历 `document.styleSheets`（要递归进 `CSSMediaRule`）收集所有 `CSSKeyframesRule`，对被使用的每个关键帧取 `keyframe.style[i]` 的属性名，断言 ⊆ {transform, opacity}。
5. **断言蒙版覆盖要给公式不要给阈值**：从 `getComputedStyle(scrim).backgroundImage` 正则解析出 stop，线性插值算文字右缘处的 alpha ≥ 0.5。
6. **`filter` 白名单要按「意图」不按「数量」**：第一版只白名单云和雾，把故意保留的闪电静态 `drop-shadow` 算成 2 处违规。
