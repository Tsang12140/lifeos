### 新学到的

1. **`height: auto` 不能参与 transition**：折叠时直接从 auto 设 0 会瞬移（第一版实测 `[292, 0, 0, …]`）。必须先读 `getBoundingClientRect().height` 钉一帧再设目标值。展开方向本来就正常，因为起点恰好是显式 `0`。
2. **编辑器容器不能长期 `overflow: hidden`**：日期面板与提及列表是绝对定位挂在里面的。裁切只在过渡期间存在，结束必须交还 `visible`。
3. **`dismissible: !isToday` 的语义坑**：`isToday` 是「当前视图是今天视图」，不是「日期是今天」。名字看着对、含义差一层。
4. **验收脚本的日期夹具不能写死（本轮真踩）**：`verify-weather-observe.mjs` 写死 `2026-09-16`/`2026-09-17`，**一过午夜就失效**，3 条断言红，看起来像产品回归。已改成 `Intl.DateTimeFormat("en-CA", { timeZone: "Asia/Shanghai" })` 动态推导。**`verify-weather-device.mjs` 有同样问题（硬编码 09-14/09-15 且断言翻到 09-15），未修；`verify-weather.mjs` 也硬编码但靠 `snapshot.today` 兜底仍 PASS（绿得侥幸）。**

### 新学到的（都值得刻死）

1. **折叠动效第一版只是碰巧通过**：用 React state 写「钉住当前高度 → 下一帧设 0」会被**批处理进同一帧**，浏览器只看到 `auto → 0` 一次变化 → 不触发 transition。修法：`useLayoutEffect` + **直接写 `slot.style.height`** + 两次写入之间 `void slot.offsetHeight` 强制回流。`useLayoutEffect` 还保证首帧就是 0，不会先全尺寸闪一下。
2. **同名 class 覆盖要带父级前缀**：`.kind-switcher` 自带 `margin: 22px 0 12px`，把我 `.review-composer-kinds { margin: 0 }` 顶掉（同优先级、它在后面）→ 条条被撑到 88px、标签下沉。改成 `.review-composer-bar .review-composer-kinds` 才生效（62px）。
3. **几何对比要在「主人实际看到的状态」下量**：展开态 CSS 会把条条 `border-width` 设成 0，于是少 1px → 报出 `371.5` vs `372.5` 的假差异。**塌缩态量条条、展开态量编辑器**才对。（那 1px 正是编辑器 `.surface` 自己的边框。）
4. **验收脚本崩溃会留下上一次的 `RESULT: PASS`**：我笔误写了不存在的 `checkTrue`，脚本抛错退出，结果文件里仍是 `RESULT: PASS (31 checks)`。已给 `verify-review-mode.mjs` 加 `uncaughtException` / `unhandledRejection` → 任何未捕获错误都改写成 `CRASH …` 并退出 1。**其它 verify 脚本还没有这层保护。**
