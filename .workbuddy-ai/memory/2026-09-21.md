## TMDB 两种凭据：LifeOS 只认 v3「API 密钥」

TMDB 后台给两样东西，**LifeOS 观影模块只能用 `API 密钥`（v3，32 位十六进制）**：
- `apps/api/src/movie.ts:169 / :228` 都是 `url.searchParams.set("api_key", key)` —— 走 v3 查询参数；
- 全仓 `Bearer` 只出现在 DeepSeek 那三处（`ai-config.ts` / `assistant.ts` / `summary.ts`），**movie 模块没有 Bearer 支持**。
- 另一张「API 读访问令牌」是 v4 JWT（`eyJ…` 开头、200+ 字符），必须放 `Authorization: Bearer` 头，当前代码传进去只会得到 TMDb 401。
- 想支持 v4 令牌 = 要改 `movie.ts` 的请求头（**未做，等主人点头**）。

### 落地结果：key 有效，但 TMDB 被墙（2026-09-21 深夜）

- 主人填的 key = **32 位十六进制 v3 key**（形状校验通过）。已走 `POST /api/movie/config` 写入
  `data/movie-config.json`（`enabled:true, hasKey:true, source:"file"`；字段 `enabled/encryptedApiKey/apiKeyIv/apiKeyTag`，
  **明文 key 全仓 0 命中**，占位文件已删）。
- **`api.themoviedb.org` 在这台机器上不可达**：DNS 解析到 `103.230.123.190`（污染 IP），TCP 443 直连**超时**。
  但 **`image.tmdb.org`（海报）是通的**、baidu 也通 → **只有 API 域名被墙**。
- **本机 7897 端口有代理在跑**（Clash/Mihomo 混合端口），对它做 `CONNECT api.themoviedb.org:443` 返回 **200**。
- **Node 的 fetch 默认不认 `HTTPS_PROXY`** —— 必须同时设 `NODE_USE_ENV_PROXY=1`（Node 24 特性）。实测：
  - `HTTPS_PROXY=http://127.0.0.1:7897` 单独设 → `UND_ERR_CONNECT_TIMEOUT`（被忽略）
  - 加上 `NODE_USE_ENV_PROXY=1` → **HTTP 200，TMDB 正常返回**（用主人的 key 实测）
  - `--env-file` 里的同名变量**会被已存在的 shell 环境变量压住**（Node 文档行为）→ 沙箱里的 `HTTPS_PROXY=49155`
    会盖掉 `.env` 的值，验证时必须注意。
  - `NO_PROXY` 生效（实测 baidu 直连、TMDB 走代理）。
- `undici` 包**没装**（`require('undici')` MODULE_NOT_FOUND）→ 想「只让 TMDB 走代理」得先加依赖。
- **已解决（主人选「`.env` 加代理」）**：
  1. `.env` 追加 `NODE_USE_ENV_PROXY=1` + `HTTPS_PROXY=http://127.0.0.1:7897` + **`NO_PROXY`（列出 DeepSeek / S3 /
     和风天气 / 海报 CDN，防止代理关掉时连累别的功能）** + 一整块注释（含「删掉这一块即可回滚」）。
  2. **`--use-env-proxy` 必须加在启动命令上** —— 这是本轮最大的坑：
     **Node 的 `NODE_USE_ENV_PROXY` 变量在 bootstrap 阶段读，早于 `--env-file` 生效 → 写进 `.env` 完全无效。**
     干净环境对照实测：`.env`(含该变量) → `TimeoutError`；同环境再加 `--use-env-proxy` → **HTTP 401（走到了）**。
     已加在 4 处：`package.json` start、`apps/api/package.json` start、`scripts/dev.mjs:20`、`.review/accept-serve.mjs:84`。
     没配代理变量时它是**空操作**。
  3. 端到端实测：`POST /api/movie/config/test` → 200「TMDb API 连接成功」；`resolve {query:"盗梦空间"}` → 3 候选、
     `tmdbId=27205`；`{imdbId:"tt1375666"}` → 27205。**观影模块可用了。**
- 验证坑：**`--env-file` 的同名变量会被已存在的 shell 环境变量压住**（沙箱自带 `HTTPS_PROXY=49155` 会盖掉 `.env`）；
  **`env -u` 在这个 bash 里无效** → 要剥环境得用 node 子进程 `delete process.env[...]` 再 spawn。
