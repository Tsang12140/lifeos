## 磁盘：清了 2.11GB，并堵住真根因（重要）

- 症状：API 测试报 `ERR_SQLITE_ERROR: database or disk is full` → **不是回归**，是 C 盘 99%（剩 4.2G）。
- 元凶：Temp 里 **92 个 `lifeos-*`**（54 个 Chrome profile + 37 个 `lifeos-api-*` 隔离 sqlite），共 **2.11GB**。
- **真根因不是"忘写清理"，是顺序**：`browser.kill()` 异步返回，紧随的 `rmSync` 在 Chrome 还活着时执行 → Windows 句柄被占 → EBUSY → 被裸 `catch {}` 吞掉。**清理代码一直在，只是从没成功过**。
  → 上一次"82 脚本 0 泄漏"是**误判**（只 grep 了 `rmSync` 在不在，没验证是否成功）。
- 修法必须是**同步强杀**：清理块多在 `const finish = () => {…}` / `process.on("exit", () => {…})` 里，`await` 非法。
