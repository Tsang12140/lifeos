## 本轮新踩到的坑（都已进 changelog / MEMORY）

1. **异步取回的状态会让「刚挂载的卡片」骗过断言**：`main.tsx:3710` 里 `movieStatus` 初值是 `{enabled:false, connected:false, …}`，真值异步到。第一版没等就断言 → 4 条假 FAIL（而同一份卡片文字 dump 里明明写着「已连接」）。**先 `waitFor` 状态落位再断言。**
2. **CDP 的 `click(expr)` 要收「求值为元素的表达式」，不是 CSS 选择器**。裸选择器塞进 `const el = ${expr}` = 页面抛语法错 → `Runtime.evaluate` 回 undefined → 报 `MISS`，而 `querySelector` 明明查得到。现在用 `$("…")` / `buttonByText("容器","文字")`。
3. **只差 hash 的 `Page.navigate` 是同文档导航** → 不能指望视图自己切回来（与 09-21 那条同源）。
4. **`reapChromeSync` 返回 true ≠ 目录真没了**：本轮早期 4 个 profile（p2rlUF / kvIuq2 / QUhzft / J9khqD）在报「已删除」的情况下留在 `.review/profiles/`。**根因没复现**（清空后连跑 3 次 + 冷启动，每次 `existsSync=false`、剩 0 个）。已手工删掉；脚本改成**自己报「运行期间新出现的 profile」+ 目录总数**，以后漏了藏不住。
5. **`node -e` 写含 `$(…)` 的文本会被 bash 当命令替换静默抹掉** —— 我在 changelog 里写 `$("选择器")` 就被吃成 `` `` ``（文件本身没坏，但少了一段）。**又违反了「先 Write 成文件再读」这条自己的规矩。** MEMORY.md 里那条已补上 `$(…)`。
